# Welcome to My Pokemon App
***

## Task
Create a functional Pokemon app using React.js that can display a list of Pokemon, show detailed information in a modal, and allow users to search for specific Pokemon.

## Description
This project is a simple Pokemon app built with React.js. It fetches data from the PokeAPI and displays a list of the first 151 Pokemon. Users can search for Pokemon by name and view detailed information about each Pokemon in a modal.

## Installation
To install the project, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/Chamis9/my_pokemon_app.git
   ```
2. Navigate to the project directory:
   ```sh
   cd my_pokemon_app
   ```
3. Install the dependencies:
   ```sh
   npm install
   ```

## Usage
To run the project locally, use the following command:
```sh
npm run dev
```
This will start the development server and open the Pokemon app in your default web browser.
